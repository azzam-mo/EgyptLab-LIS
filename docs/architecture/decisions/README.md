## Template for new ADRs

```markdown
# ADR-000N — Short title

Status: Proposed | Accepted | Superseded
Date: YYYY-MM-DD
Owner: name / role

## Context
What situation, constraint, or requirement forces a decision?

## Options
1. Option A — consequences.
2. Option B — consequences.

## Selected approach
What was chosen and why.

## Risks
What can go wrong and how it will be managed.

## Approval
Who approved it, and when.
```
